# 🔷 O que é Node.js

Tecnologia que permite usar JavaScript não sóno navegador, mas no servidor/backend também, permitindo que junto com o JavaScript, seja possível criar
servidores,conectar bancos de dados criar APIs, fazer automações, criar backend.

## Usos

Muito usado para criar APIs REST, na parte de login, cadastro, produtos e pagamentos.
Lida bem com conexões instantâneas por isso também é muito usado para chats em tempo real.
Muito usado para processos de automações, escrevendo Scripts para mover arquivos, enviar emails, consumir APIs, bots.
