#  🔷 que é Redux

Redux é uma biblioteca para gerenciar o estado global de uma aplicação React, facilitando facilitando o compartilhamento de dados entre diferentes componentes.

## Core Redux Concepts

### Store:
Esse é o único lugar no qual todos os estados do app de encontram. São os dados armazenados

### Action:
É uma ação que informa o que aconteceu.

### Reducer:
É uma função que recebe uma ação e decide como atualizar o estado.
