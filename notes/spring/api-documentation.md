# 🔷 Swagger

É um conjunto de ferramentas e especificações pra documentação de REST APIs.

## Porque documentar APIs?

Imagine que você criou uma REST API, como os outros vão saber como usar? Você pode pensar na documentação como um manual
da sua API.

### Sem documentação
- As APIs ficam confusas
- Colaboração se torna complicada
- Adicionar novo membros ao time se torna difícil e lenta a adaptação

### Com boa documentação
- APIs claras e fáceis de entender
- Endpoint explicados, request/responses, Http status codes, regras de autenticação e exemplos, tudo muito bem explicado
- Interativo (testável via browser).
