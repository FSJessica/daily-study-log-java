# O que é Spring Boot

Spring Boot é um framework Java amplamente utilizado que facilita o desenvolvimento de aplicações APIs e sistemas web.
O spring boot automatiza diversos processos e etapas.
Pode ser usado para:

- APIs REST
- sistemas de cadastro
- e-commerces
- sistemas bancários
- microsserviços
- aplicações web

Por mais capaz e abrangente que o Spring Framework seja, ainda requer tempo e conhecimento significativos para 
configurar, instalar e implementar aplicações Spring. O Spring Boot mitiga esse esforço com três recursos importantes.

### Autoconfiguração:
O Java Spring Boot vem com recursos de autoconfiguração integrados, que configuram automaticamente o
Spring Framework subjacente e pacotes de terceiros com base em suas configurações. Essa abordagem, baseada nas melhores
práticas, ajuda a evitar erros.
A funcionalidade de autoconfiguração do Java Spring Boot permite que você comece a desenvolver rapidamente suas 
aplicações baseadas em Spring e reduz a possibilidade de erros humanos.

### Uma abordagem opinativa para configuração
Você pode definir as necessidades do seu projeto durante o processo de inicialização, durante o qual você escolhe entre
várias dependências iniciais — chamadas Spring Starters— que abrangem casos de uso típicos. Para executar o Spring Boot
Bootizr, preencha um formulário da web simples, sem qualquer codificação.

### A capacidade de criar aplicações independentes
O Spring Boot ajuda os desenvolvedores a criar aplicações que simplesmente são executadas. Especificamente, você pode
criar aplicações independentes que são executadas por conta própria, sem depender de um servidor web externo.

## Os blocos de construção que fazem o Spring Boot funcionar

### Microsserviços
Microsserviços são uma abordagem para criar software em que um aplicativo é dividido em componentes pequenos e
independentes, cada um responsável por uma função específica. Em vez de criar um sistema grande e fortemente conectado,
os microsserviços permitem que as equipes desenvolvam, implantem e dimensionem partes individuais de um aplicativo de
forma independente. Essa arquitetura torna os aplicativos mais resilientes, mais fáceis de manter e mais rápidos
de atualizar.

### Injeção de dependência
A injeção de dependência (DI) é uma técnica de design que gerencia esses relacionamentos automaticamente, passando os
recursos certos para os componentes certos sem exigir que os desenvolvedores codifiquem essas conexões manualmente.

### Convenção em vez de configuração
Esse princípio reduz o número de decisões que um desenvolvedor precisa tomar ao estabelecer padrões sensatos. Em vez de 
escrever arquivos de configuração para cada aspecto de um aplicativo, os desenvolvedores só precisam especificar as 
partes que fogem do padrão. Isso deixa as bases de código mais enxutas e os ciclos de desenvolvimento mais curtos.

### Suporte a servidor autônomo
Tradicionalmente, implantar um aplicativo Java exigia configurar e gerenciar um servidor web separado. O Spring Boot 
muda isso ao incluir servidores populares como Apache Tomcat e Jetty diretamente no aplicativo. Isso significa que as
equipes podem executar e implantar seus aplicativos sem nenhuma configuração adicional de servidor, acelerando bastante
o desenvolvimento e a implantação.

### Pacotes de bibliotecas prontos para uso
As dependências iniciais são pacotes pré-configurados de bibliotecas que dão aos desenvolvedores tudo o que precisam 
para dar suporte a um recurso ou funcionalidade específica, sem ter que procurar e configurar cada uma delas. Elas são
um dos principais motivos pelos quais os aplicativos Spring Boot podem sair da ideia para o código em execução tão rápido.
