# 🔷 Deployment

Quando uma aplicação tem seu desenvolvimento concluído, o desenvolvedor pode colocar esse app em funcionamento para que
todos consigam acesso. Esse processo é chamado de Deploy.

## Plataformas mais utilizadas

Para facilitar o processo, algumas plataformas cloud podem ser usadas, algumas delas:
- Amazon Web Services
- Google Cloud
- Microsoft Azure
- Railway
- Render
- Heroku
- VPS Linux
- Docker containers
